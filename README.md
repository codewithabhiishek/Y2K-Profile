## ⚡ What is PROFILE.EXE?

**PROFILE.EXE** is a full-featured, self-contained **GitHub Profile README builder**, **theme engine**, and **SVG widget studio** — built with Y2K aesthetics and zero compromises.

It transforms any public GitHub handle into **high-craft Markdown READMEs** with:
- 🖥️ Interactive `<details>` drawers and animated SVG headers
- 🎨 CRT scanline banners, deterministic pixel avatars, and telemetry cards
- 🤖 AI-powered README compilation with multi-model fallback
- 📦 7 downloadable, zero-dependency pure SVG widgets

> No paywalls. No watermarks. No rate limits.

---

## 🕹️ Feature Modules

| Module | Name | What It Does |
| :---: | :--- | :--- |
| `01` | **AI README Compiler** | Real-time GitHub scraping · multi-model fallback · 4 tone presets · 7-style ASCII art · live split editor · one-click critique/refine |
| `02` | **10 Themed Templates** | Hand-crafted visual blueprints matching every theme skin · auto-populates with your live GitHub handle |
| `03` | **SVG Asset Studio** | 7 downloadable pure SVGs: Holographic Banner · Tech Matrix · Pixel Avatar · Y2K BIOS Card · RPG Radar · Telemetry Card · 3D Wordmark |
| `04` | **GitHub Wrapped** | Annual year-in-review infographic (520×716) · one-click Markdown portfolio from your top repos |

## 🚀 Quick Start

### 1. Clone & Install

```bash
git clone https://github.com/codewithabhiishek/Y2K-Profile.git
cd Y2K-Profile
npm install
```

### 2. Configure AI *(Optional)*

```bash
cp .env.example .env
# Add your Groq API key for higher rate limits & custom models
# GROQ_API_KEY="gsk_your_key_here"
```

### 3. Launch Dev Server

```bash
npm run dev
# → Open http://localhost:3000
```

### 4. Build for Production

```bash
npm run build && npm run preview
```

## 📂 Project Structure

```
Y2K-Profile/
├── index.html          # Self-contained app (core lives here)
│   ├── <style>         # CSS: themes, CRT atmosphere, responsive layout
│   ├── <script>        # Block 1: core utils, themes, ASCII library
│   ├── <script>        # Block 2: template markdown data (10 themes × 5 sections)
│   └── <script>        # App: renderer, SVG generators, AI compiler
├── api/
│   └── generate.js     # Vercel serverless function for AI README compilation
├── src/                # React entry point (minimal — app bootstrapped in HTML)
├── vite.config.js      # Build config with single-file output strategy
└── vercel.json         # Edge routing & serverless function config
```
